The successor of [CliRenderer](https://github.com/ultraflame4/CliR) written in [**Rust**](https://rust-lang.org/).
It is roughly ~4x faster than the python version


This commandline programs takes in image and renders it into the terminal using braille and other unicode characters.

Use terminals with 256 color support for best experience (ie. Windows Terminal)
